## [Unreleased]

### Features

- Initial design system with 15 components
- Design tokens (colors, typography, spacing, shadows, borders, motion, breakpoints)
- Theme system (light/dark/system) with CSS custom properties
- Tailwind CSS v4 integration via `@theme` and `@source`
- Custom `data-nova-test` attribute system for testing
- 7 custom hooks (useTheme, useClickOutside, useMediaQuery, useFocusTrap, useKeyboardNav, useId, useNovaTestId)
- 143 unit tests with vitest-axe a11y audits
- Biome + ESLint (sonarjs) + Prettier (TW class sorting)
- Husky + Commitlint (conventional commits)
- Jenkins CI pipeline
- Consumer example templates (Vite, Next.js)

### Components

- `NovaButton` — polymorphic, forwardRef, variants, sizes, loading, icons
- `NovaText` — polymorphic, fluid type scale, weights, colors
- `NovaHeading` — polymorphic, auto semantic heading tags (h1-h6)
- `NovaInput` — label, error, helper, addons, controlled/uncontrolled
- `NovaBadge` — variants, sizes, dot indicator
- `NovaAvatar` — image with fallback initials
- `NovaSpinner` — accessible loading indicator
- `NovaCard` — compound (Header, Body, Footer)
- `NovaCheckbox` — label, indeterminate, a11y
- `NovaRadioGroup` + `NovaRadio` — compound, context-based
- `NovaSwitch` — role="switch", sizes
- `NovaTabs` — compound, keyboard nav, roving tabindex
- `NovaModal` — compound, focus trap, portal, scroll lock
- `NovaTooltip` — hover/focus, positions, Escape dismiss
- `NovaToastProvider` + `useToast` — auto-dismiss, variants, live regions
- `NovaTable` — compound, semantic HTML, striped, bordered
